# 11.1 Exchange Online Admin (Shared Mailboxes)

## Konzept: Warum Freigegebene Postfächer?

Ein freigegebenes Postfach (Shared Mailbox) ist ein Postfach, das von mehreren Benutzern gleichzeitig gelesen und zum Senden von E-Mails verwendet werden kann. Typische Anwendungsfälle sind allgemeine Adressen wie `info@example.com` oder `support@example.com`.

**Die strategischen Vorteile:**

- **Kostenlos:** Eine Shared Mailbox benötigt **keine eigene Microsoft 365 Lizenz**. Sie bietet dennoch standardmäßig 50 GB Speicherplatz.
- **Zentrale Ablage:** Alle berechtigten Benutzer sehen dieselben E-Mails im Posteingang und die gesendeten Antworten.
- **Sicherheit:** Eine Shared Mailbox hat kein eigenes Passwort. Ein Angreifer kann sich nicht direkt an `info@...` anmelden. Der Zugriff erfolgt immer legitimiert über das persönliche, lizenzierte Benutzerkonto (z. B. `schulung@example.com`).

## Schritt 1: Erstellung der Shared Mailbox

Wir erstellen das Postfach zentral im Microsoft 365 Admin Center.

**1.1** Melden Sie sich als globaler Administrator (`mika.varga@example.com`) unter `admin.microsoft.com` an.

**1.2** Navigieren Sie im linken Menü zu **Teams & Gruppen** → **Freigegebene Postfächer**.

**1.3** Klicken Sie auf **Freigegebenes Postfach hinzufügen**.

**1.4 Name:** Tragen Sie `Info-Desk` ein.

**1.5 E-Mail-Adresse:** Tragen Sie `info` ein. Die Domäne `@example.com` sollte automatisch ergänzt werden.

**1.6** Klicken Sie auf **Änderungen speichern**. Das Postfach wird nun im Hintergrund im Exchange Online provisioniert.

## Schritt 2: Berechtigungen delegieren

Damit Ihre Benutzer auf das Postfach zugreifen dürfen, müssen wir ihnen Rechte zuweisen. Wir berechtigen den in Modul 6 synchronisierten Lab-User.

**2.1** Klicken Sie in der Liste der freigegebenen Postfächer auf das neu erstellte Postfach **Info-Desk**.

**2.2** Klicken Sie im sich öffnenden Detail-Fenster unter *Mitglieder* auf **Bearbeiten**.

**2.3** Klicken Sie auf **Mitglieder hinzufügen**.

**2.4** Suchen Sie nach dem Benutzer **Schulung** (`schulung@example.com`) sowie Ihrem eigenen **Produktiv-Account** und setzen Sie die Haken.

**2.5** Klicken Sie auf **Speichern**.

*Hinweis zu den Rechten:* Durch diesen Schritt erhalten die Benutzer automatisch zwei Exchange-Berechtigungen: **Vollzugriff** (Lesen/Löschen) und **Senden als** (E-Mails verfassen, bei denen der Absender „Info-Desk“ ist).

## Schritt 3: Zugriffstest via Outlook im Web (OWA)

Wir verifizieren nun, ob der Lab-Benutzer das neue Postfach nutzen kann.

**3.1** Melden Sie sich an Ihrem Windows-Client (`CL-WIN-01`) als `schulung@example.com` an.

**3.2** Öffnen Sie den Browser und rufen Sie `https://outlook.office.com` auf.

**3.3** Klicken Sie oben rechts auf den Kreis mit Ihren Initialen (das Profilbild).

**3.4** Wählen Sie **Anderes Postfach öffnen...**

**3.5** Tippen Sie `info@example.com` ein und bestätigen Sie mit **Öffnen**.

**3.6 Ergebnis:** Ein neuer Tab öffnet sich mit dem Posteingang der Shared Mailbox. Sie können nun eine Test-E-Mail senden, um zu prüfen, ob das „Senden als“ Recht erfolgreich angewendet wurde.

> [!IMPORTANT]
> **Hybrid-Architektur Exkurs (Wichtig für das Portfolio!)**\
> Da Sie eine hybride Umgebung mit Entra Connect (Modul 6.2) betreiben, fällt hier ein interessantes Detail auf: Wir haben die Shared Mailbox als „Cloud-Only“ Objekt erstellt. Sie existiert in Ihrem lokalen Active Directory (`SRV-DC-01`) **nicht**.
>
> In strikten Enterprise-Umgebungen würde man stattdessen im lokalen AD ein deaktiviertes Benutzerkonto anlegen, ihm spezielle Exchange-Attribute mitgeben und es durch Entra Connect in die Cloud synchronisieren lassen, wo es dann zu einer Shared Mailbox konvertiert wird. Für kleinere bis mittlere Architekturen (wie dieses Lab) ist die direkte Erstellung in der Cloud jedoch der Microsoft Best-Practice Weg zur Reduzierung lokaler Abhängigkeiten (Modern Management).

> [!TIP]
> **Praxis-Tipp: Auto-Mapping im Outlook Client**\
> Wenn der Benutzer an seinem Windows-Client die lokale Desktop-App von Microsoft Outlook installiert hat, muss er das Postfach nicht manuell hinzufügen. Dank des Features **Auto-Mapping** erscheint die Shared Mailbox nach 30 bis 60 Minuten vollautomatisch als zweiter Posteingang unten in der linken Navigationsleiste von Outlook.
