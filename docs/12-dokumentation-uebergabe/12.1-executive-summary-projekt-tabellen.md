# 12.1 Executive Summary & Projekt-Tabellen

## Projekt-Zusammenfassung (Executive Summary)

Dieses Dokument fasst die architektonischen, infrastrukturellen und sicherheitstechnischen Errungenschaften des „Multi-Site Hybrid Cloud & AI-Sec Operations“ Enterprise-Homelabs zusammen. Das Projekt demonstriert tiefgehendes Fachwissen im Aufbau einer hybriden Unternehmens-IT (On-Premises & Microsoft 365), gepaart mit modernsten Konzepten aus den Bereichen **AI-Security Operations (Autonomes SIEM)**, **Zero Trust Network Access** und **Disaster Recovery**.

## Tabelle 5: Security- & Härtungs-Maßnahmen

Übersicht der implementierten Schutzkonzepte (Defense in Depth).

| **Konzept** | **Implementierung im Projekt** |
| --- | --- |
| **AD Tier-Modell** | Strikte Trennung in Tier 0 (Identität), Tier 1 (Server) und Tier 2 (Clients). Tier-0 Konten dürfen sich nicht an Workstations anmelden. |
| **LAPS** | Automatische Rotation individueller lokaler Admin-Passwörter für Windows-Clients zur Verhinderung von Pass-the-Hash / Lateral Movement. |
| **Zero Trust (Cloud)** | Security Defaults & MFA für alle M365 Benutzer, Blockierung von Legacy-Protokollen, Intune Mobile Device Management. |
| **Split-Brain DNS** | Verhindert Hairpin-NAT. Interne Anfragen an Webdienste werden direkt in die DMZ aufgelöst, externe Anfragen an die öffentliche IONOS-IP. |
| **Autonomous SIEM** | Windows Event Forwarding & rsyslog pushen Daten an Kali. Ein Python-Daemon nutzt Ollama zur Echtzeit-Angriffserkennung und alarmiert via Teams. |
| **3-2-1 Backup** | Veeam auf ReFS (Fast Clone). 1. Kopie: Hyper-V, 2. Kopie: NAS (iSCSI), 3. Kopie: Google Drive (Cloud) via rclone AES-256 verschlüsselt. |
| **Layer 7 Security** | Suricata Intrusion Prevention System (IPS) auf OPNsense aktiviert, Reverse Proxy (Apache) verschleiert interne IPs (wie das NAS). |
