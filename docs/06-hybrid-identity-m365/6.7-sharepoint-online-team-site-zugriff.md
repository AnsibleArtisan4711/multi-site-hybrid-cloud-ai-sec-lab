# 6.7 SharePoint Online & Team-Site Zugriff

## Konzept: Zentrale Datenhaltung in der Cloud

Während OneDrive for Business primär für persönliche Arbeitsdateien gedacht ist, bildet **SharePoint Online** das Rückgrat für die Zusammenarbeit in Teams. Eine Team-Site dient als zentrales Portal für Dokumente, News und gemeinsame Listen. In diesem Modul verifizieren wir, dass der hybride Benutzer `schulung@example.com` nahtlos auf diese Ressourcen zugreifen kann.

## Schritt 1: Erstellung der Team-Site

Dieser Schritt wird von Ihrem globalen Administrator (`mika.varga@...`) durchgeführt.

**1.1** Öffnen Sie das **SharePoint Admin Center**: `https://admin.microsoft.com/sharepoint`.

**1.2** Navigieren Sie zu **Websites** → **Aktive Websites**.

**1.3** Klicken Sie auf **Erstellen** und wählen Sie den Typ **Teamwebsite**.

**1.4 Websitename:** `Lab-Projekt-Alpha`

**1.5 Gruppenbesitzer:** `mika.varga@example.com`

**1.6** Klicken Sie auf **Weiter** und anschließend auf **Fertig stellen**.

## Schritt 2: Berechtigungsmanagement (Role-Based Access)

Damit der synchronisierte Benutzer Zugriff erhält, muss er der zugrunde liegenden Microsoft 365 Gruppe hinzugefügt werden.

**2.1** Klicken Sie in der Liste der aktiven Websites auf **Lab-Projekt-Alpha**.

**2.2** Wechseln Sie in den Reiter **Mitgliedschaft**.

**2.3** Klicken Sie unter **Mitglieder** auf **Hinzufügen**.

**2.4** Suchen Sie nach dem Benutzer **Schulung** (`schulung@example.com`) und fügen Sie ihn hinzu.

**2.5 Verifizierung:** Der Benutzer sollte nun als *Mitglied* gelistet sein.

## Schritt 3: Zugriffstest am Client

Wir validieren den Zugriff vom Windows-Client (`CL-WIN-01`) aus.

**3.1** Melden Sie sich am Client als `schulung@example.com` an.

**3.2** Öffnen Sie Microsoft Edge und rufen Sie `https://contoso.sharepoint.com` auf.

**3.3** Dank **Seamless SSO** (Modul 6.3) erfolgt die Anmeldung automatisch.

**3.4** Klicken Sie auf die Website **Lab-Projekt-Alpha**.

**3.5 Dokumenten-Test:**

- Navigieren Sie zu **Dokumente**.
- Erstellen Sie ein neues Word-Dokument mit dem Namen `Test-Infrastruktur.docx`.
- Schreiben Sie einen kurzen Text und speichern Sie.

## Schritt 4: Synchronisation mit dem Explorer (Optional)

Um den Komfort für den Benutzer zu erhöhen, binden wir die SharePoint-Bibliothek direkt in den Windows Explorer ein.

**4.1** Klicken Sie in der SharePoint-Dokumentenbibliothek oben auf die Schaltfläche **Synchronisieren**.

**4.2** Der OneDrive-Client auf dem Windows-PC öffnet sich automatisch.

**4.3 Ergebnis**: Im Datei-Explorer erscheint links ein neues Symbol mit einem kleinen Firmengebäude. Dort finden Sie den Ordner *Lab-Projekt-Alpha - Dokumente*. Die Dateien werden nun lokal angezeigt, liegen aber physisch in der Cloud.

> [!NOTE]
> **Portfolio-Tipp: SharePoint als Basis für Teams**\
> Erklären Sie in Ihrem Bericht den architektonischen Zusammenhang: Jedes Mal, wenn ein Team in *Microsoft Teams* erstellt wird, generiert Microsoft im Hintergrund automatisch eine SharePoint Team-Site. Die Dateien, die Sie in einem Teams-Kanal hochladen, werden technisch gesehen in der SharePoint-Dokumentenbibliothek gespeichert, die Sie gerade konfiguriert haben. SharePoint ist somit der „Speicher-Motor“ für die moderne Zusammenarbeit.

> [!IMPORTANT]
> **Sicherheitshinweis: Externes Teilen**\
> Standardmäßig erlaubt SharePoint das Teilen von Dokumenten mit externen Personen (Gästen). Prüfen Sie im SharePoint Admin Center unter *Richtlinien* → *Freigabe*, ob dies für Ihre Lab-Umgebung gewünscht ist, oder ob Sie den Zugriff aus Sicherheitsgründen auf *„Nur Personen in Ihrer Organisation“* einschränken möchten.
