# 0.5 Lizenz-Management

## Übersicht der Projekt-Lizenzen

Da es sich bei diesem Projekt um ein *Enterprise-Grade Homelab* handelt, wird eine Kombination aus kostenfreien Evaluierungsversionen für die lokale Infrastruktur und kommerziellen Cloud-Abonnements für die Hybrid-Szenarien genutzt. Ein sauberes Management dieser Lizenzen ist essenziell, um Laufzeit-Unterbrechungen zu vermeiden.

## \1. Lokale Infrastruktur (On-Premises)

Für die lokalen Windows-Server (z. B. `SRV-DC-01`, `SRV-DC-02`) werden **Windows Server Evaluation Keys** verwendet.

- **Laufzeit:** 180 Tage ab Installation.
- **Verlängerung (Rearm):** Die Evaluierungsperiode kann über die administrative Kommandozeile (CMD) mit dem Befehl `slmgr -rearm` bis zu sechsmal verlängert werden, was eine maximale Gesamtlaufzeit von rund 3 Jahren für das Lab ermöglicht.
- **Aktivierung:** Die Aktivierung erfolgt automatisch über das Internet. Für Systeme in der DMZ (sofern Windows-basiert) müssten temporäre Firewall-Regeln zur Aktivierung bedacht werden.

## \2. Cloud Services (Microsoft 365 & Entra ID)

Um die Hybrid-Features (Modul 6) wie Azure AD Connect (Entra Connect) und Seamless SSO abzubilden, wird ein Microsoft 365 Tenant eingerichtet.

| **Cloud-Ressource** | **Einsatzgebiet im Projekt** |
| --- | --- |
| **M365 Business Basic** | Bereitstellung der primären Cloud-Identitäten. Zuweisung der Lizenzen an synchronisierte On-Premises User, um Exchange Online (Mail) und SharePoint/OneDrive (1TB) zu aktivieren. |
| **Entra ID (Free)** | Ist automatisch im M365-Abonnement enthalten. Dient als Ziel für die Password Hash Synchronization (PHS) der lokalen Active Directory Benutzer. |
| **Google One (5TB)** | Nutzung als Offsite-Backup-Ziel für Veeam (Modul 10). Die Einbindung erfolgt später via `rclone` oder RaiDrive. |

**Wichtiger Vorbereitungsschritt (Tenant-Setup):**\
Bevor die lokalen Server aufgesetzt werden, muss der initiale Microsoft 365 Tenant erstellt werden (z. B. `contoso.onmicrosoft.com`). Anschließend muss die externe Domain **`example.com`** im M365 Admin Center als benutzerdefinierte Domäne hinzugefügt und per TXT-Record im öffentlichen DNS verifiziert werden.
