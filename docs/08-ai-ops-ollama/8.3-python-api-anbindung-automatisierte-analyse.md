# 8.3 Python API-Anbindung (Automatisierte Analyse)

## Konzept: Die KI-Schnittstelle

Ollama bietet standardmäßig eine REST-API an, die auf Port `11434` lauscht. Um nicht jedes Log manuell in den Chat kopieren zu müssen, nutzen wir ein Python-Skript auf dem **`CL-KALI-01`**.

Das Skript fungiert als „Pipeline-Manager“:

1. Es scannt den Ordner `/var/lib/siem-hub/windows-json/` nach neuen Dateien.
2. Es extrahiert die relevantesten Events.
3. Es formuliert einen präzisen Prompt für die KI (Ollama).
4. Es speichert die KI-Bewertung im Ordner `/var/lib/siem-hub/analysis/`.

## Schritt 1: Python-Umgebung vorbereiten

Kali Linux bringt Python 3 bereits mit. Wir benötigen lediglich die `requests`-Bibliothek für die Kommunikation mit der API.

**Installation der Abhaengigkeiten**

```bash
sudo apt update
sudo apt install python3-requests python3-pandas -y
```

## Schritt 2: Erstellung des Analyse-Skripts

Erstellen Sie im Verzeichnis `/home/kali/scripts/` die Datei `ai_log_analyzer.py`.

**Python-Skript: ai\_log\_analyzer.py**

```python
import requests
import json
import os

# Konfiguration
OLLAMA_URL = "http://localhost:11434/api/generate"
MODEL = "llama3"
LOG_DIR = "/var/lib/siem-hub/windows-json/"
OUTPUT_DIR = "/var/lib/siem-hub/analysis/"

def analyze_logs(log_data):
    # System-Prompt definieren fuer bessere KI-Antworten
    prompt = f"Du bist ein Cyber-Security Analyst. Analysiere folgende Windows-Logdaten im JSON-Format auf Anomalien oder Angriffszeichen (z.B. Brute Force, unbefugte Admin-Erstellung). Antworte kurz und praezise: \n\n {log_data}"
    payload = {
        "model": MODEL,
        "prompt": prompt,
        "stream": False # Wir wollen die Antwort als einen Block
    }

    try:
        response = requests.post(OLLAMA_URL, json=payload)
        return response.json().get('response', 'Fehler in der Antwort.')
    except Exception as e:
        return f"API-Verbindungsfehler: {str(e)}"

# Hauptschleife: Scanne Dateien
for file in os.listdir(LOG_DIR):
    if file.endswith(".json"):
        with open(os.path.join(LOG_DIR, file), 'r') as f:
            data = f.read()
            print(f"Analysiere Datei: {file}...")
            result = analyze_logs(data)

            # Ergebnis speichern
            output_file = f"Analysis_{file.replace('.json', '.txt')}"
            with open(os.path.join(OUTPUT_DIR, output_file), 'w') as out:
                out.write(result)
            print(f"Ergebnis gesichert in {output_file}")
```

*Als Datei:* [`scripts/08-ai-ops-ollama/ai_log_analyzer.py`](../../scripts/08-ai-ops-ollama/ai_log_analyzer.py)

## Schritt 3: Skript-Testlauf

Stellen Sie sicher, dass sich Testdaten im Ordner befinden und führen Sie das Skript aus:

```bash
python3 /home/kali/scripts/ai_log_analyzer.py
```

## Schritt 4: Verifizierung im SIEM-Portal

Prüfen Sie die generierten Dateien im Analyse-Verzeichnis:

```bash
cat /var/lib/siem-hub/analysis/Analysis_WinEvents_*.txt
```

*Ergebnis:* Sie sollten eine menschlich lesbare Einschätzung der KI sehen, ob die vorliegenden Windows-Events unbedenklich sind oder eine Warnung darstellen.

> **Portfolio-Check: Automatisierung & Skalierbarkeit**\
