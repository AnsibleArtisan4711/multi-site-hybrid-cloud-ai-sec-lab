# 3.2 SDC Promotion (Site Replication)

## Rolle des Secondary Domain Controllers (SDC)

Der `SRV-DC-02` fungiert als zusätzlicher Domain Controller für die Filiale. Sein Einsatz hat zwei Hauptgründe:

1. **Hochverfügbarkeit:** Fällt der PDC im HQ aus, können sich Benutzer in der Filiale (und im HQ) weiterhin anmelden.
2. **Performance:** Anmeldeanfragen und DNS-Abfragen der Filial-Clients werden lokal beantwortet, anstatt jedes Mal über den VPN-Tunnel zum HQ gesendet werden zu müssen.

## Schritt 1: Netzwerk-Konfiguration in der Filiale

Damit der `SRV-DC-02` den Forest finden kann, ist die DNS-Einstellung kritisch.

**1.1 Hostname setzen:** Ändern Sie den Namen auf **`SRV-DC-02`**.

**1.2 Statische IP konfigurieren (Host 2):**

- **IP-Adresse:** `10.0.30.10`
- **Subnetzmaske:** `255.255.255.0`
- **Gateway:** `10.0.30.1` (OPNsense Filiale)
- **Bevorzugter DNS:** `10.0.10.10` (Wichtig: Zeigt auf den PDC im HQ, um die Domäne initial zu finden).

**1.3 Erreichbarkeitstest:** Führen Sie einen `ping ad.example.com` aus. Erhält der Server eine Antwort vom PDC (10.0.10.10), steht die Route durch den VPN-Tunnel.

## Schritt 2: Promotion zum zusätzlichen Domain Controller

**2.1** Installieren Sie die Rolle *Active Directory-Domänendienste* (AD DS) wie in Modul 3.1 beschrieben.

**2.2** Klicken Sie auf ***Server zu einem Domänencontroller heraufstufen***.

**2.3 Bereitstellungskonfiguration:** Wählen Sie ***Domänencontroller einer vorhandenen Domäne hinzufügen***.

**2.4 Domäne:** Geben Sie `ad.example.com` ein. Klicken Sie auf *Auswählen* und geben Sie die Zugangsdaten von `EXAMPLE\Administrator` ein.

**2.5 Optionen:** Stellen Sie sicher, dass **DNS** und **Globaler Katalog (GC)** aktiviert sind.

**2.6 Replikationsoptionen:** Wählen Sie unter *„Replizieren von:“* explizit den **`SRV-DC-01.ad.example.com`** aus.

**2.7** Führen Sie die Installation durch. Der Server startet nach der erfolgreichen Replikation der Datenbank neu.

## Schritt 3: Standort-Optimierung (AD Sites & Services)

Nach dem Neustart müssen wir Windows mitteilen, dass sich die beiden DCs an unterschiedlichen physischen Standorten befinden.

**3.1** Öffnen Sie auf dem PDC (`SRV-DC-01`) das Tool **Active Directory-Standorte und -Dienste**.

**3.2 Standorte umbenennen:** Benennen Sie *Default-First-Site-Name* in **HQ** um. Erstellen Sie einen neuen Standort namens **Filiale**.

**3.3 Subnetze zuweisen:**

- Erstellen Sie ein neues Subnetz `10.0.10.0/24` und weisen Sie es **HQ** zu.
- Erstellen Sie ein neues Subnetz `10.0.30.0/24` und weisen Sie es **Filiale** zu.

**3.4 Server verschieben:** Ziehen Sie das Server-Objekt `SRV-DC-02` in den Standort **Filiale**.

> [!TIP]
> **Prüfung der Replikation (Best Practice):**\
> Öffnen Sie die administrative PowerShell auf einem der DCs und führen Sie den Befehl `repadmin /showrepl` aus. Wenn alle Statustexte *„Erfolgreich“* bzw. *„Successful“* melden, ist Ihre Multi-Site-Replikation über den VPN-Tunnel aktiv.

## Schritt 4: Finalisierung DNS

Ändern Sie nun auf `SRV-DC-02` die DNS-Einstellungen:

- **Bevorzugter DNS:** `127.0.0.1` (Lokal)
- **Alternativer DNS:** `10.0.10.10` (HQ)
