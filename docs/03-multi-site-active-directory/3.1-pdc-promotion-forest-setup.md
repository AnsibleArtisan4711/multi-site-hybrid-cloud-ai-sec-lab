# 3.1 PDC Promotion (Forest Setup)

## Voraussetzungen für den Domain Controller

Bevor die Active Directory Domain Services (AD DS) installiert werden können, muss das Basis-Betriebssystem (Windows Server Evaluation) auf der VM `SRV-DC-01` installiert sein. Stellen Sie sicher, dass die VM gemäß Modul 1.6/1.7 mit **4 GB statischem RAM** und dem **vSwitch-LAN** konfiguriert ist.

## Schritt 1: Netzwerk- & Hostname-Vorbereitung

Ein Domain Controller darf seine IP niemals per DHCP beziehen.

**1.1 Hostname setzen:** Ändern Sie den Computernamen in der Systemsteuerung auf **`SRV-DC-01`**. Starten Sie den Server neu.

**1.2 Statische IP konfigurieren:**

- **IP-Adresse:** `10.0.10.10`
- **Subnetzmaske:** `255.255.255.0` (/24)
- **Gateway:** `10.0.10.1` (OPNsense HQ)
- **DNS-Server:** `127.0.0.1` (Der DC wird sein eigener DNS-Server)

## Schritt 2: Installation der AD DS Rolle

Dies erfolgt über den Server-Manager oder effizienter per PowerShell.

**AD DS Rolleninstallation**

```powershell
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
```

## Schritt 3: Heraufstufung zum Domain Controller (Promotion)

Nach der Installation der Binärdateien muss der Server zum Domain Controller befördert werden.

**3.1** Klicken Sie im Server-Manager auf das gelbe Warnsymbol und wählen Sie ***Server zu einem Domänencontroller heraufstufen***.

**3.2 Bereitstellungskonfiguration:** Wählen Sie ***Neuen Gesamtstruktur (Forest) hinzufügen***.

**3.3 Stammdomänenname:** Geben Sie **`ad.example.com`** ein (siehe Modul 0.4).

**3.4 Optionen für Domänencontroller:**

- *Funktionsebene:* Windows Server 2016 (oder höher).
- *DNS-Server* und *Globaler Katalog (GC)* müssen aktiviert sein.
- Vergeben Sie ein sicheres Kennwort für den **Verzeichnisdienste-Wiederherstellungsmodus (DSRM)**.

**3.5 NetBIOS-Name:** Bestätigen Sie `EXAMPLE` (wird automatisch vorgeschlagen).

**3.6 Pfade:** Belassen Sie die Pfade für NTDS-Datenbank, Protokolle und SYSVOL auf Standard.

**3.7 Prüfung:** Bestätigen Sie die Installation. Der Server startet nach Abschluss automatisch neu.

## Schritt 4: Post-Installation & DNS-Prüfung

Nach dem Neustart melden Sie sich als `EXAMPLE\Administrator` an.

- **DNS-Reverse-Lookup-Zone:** Öffnen Sie das DNS-Management-Tool und erstellen Sie eine neue *Reverse-Lookup-Zone* für das Netzwerk `10.0.10.x`. Dies ist essenziell für die korrekte Funktion von Kerberos.
- **DNS-Weiterleitung:** Konfigurieren Sie in den Eigenschaften des DNS-Servers eine Weiterleitung (Forwarder) zur OPNsense (`10.0.10.1`) oder zu einem öffentlichen DNS (`8.8.8.8`), damit der DC Namen im Internet auflösen kann.

> [!NOTE]
> **Zentrale Rolle: Der PDC Emulator**\
> Da dies der erste Domain Controller im Forest ist, hält `SRV-DC-01` automatisch alle fünf FSMO-Rollen (Flexible Single Master Operations), einschließlich der des **PDC Emulators**. Er ist die autoritative Zeitquelle für das gesamte Netzwerk. Stellen Sie sicher, dass die Uhrzeit des Hosts und der VM korrekt ist.
