# 2.1 Firewall Installation (OPNsense)

## Architektonische Rolle der Firewalls

Die Firewalls bilden das Herzstück beider Standorte. Sie fungieren als Default-Gateway, regeln das NAT (Network Address Translation) ins Internet, isolieren die DMZ und bauen den verschlüsselten VPN-Tunnel zwischen dem Hauptquartier (Host 1) und der Filiale (Host 2) auf. Als Betriebssystem kommt das FreeBSD-basierte **OPNsense** zum Einsatz.

Diese Installation muss exakt identisch auf beiden zuvor erstellten VMs (`FW-HQ-01` und `FW-FIL-01`) durchgeführt werden.

## Schritt-für-Schritt: Installation des Basis-Systems

1. **Sicherheitsprüfung (Secure Boot):**\
   Wie in Modul 1.6 dokumentiert, stellen Sie sicher, dass in den Hyper-V Einstellungen beider Firewall-VMs unter *Sicherheit* der Haken bei ***Sicheren Start aktivieren*** **(Secure Boot) entfernt** ist. FreeBSD bootet in Hyper-V Gen2 VMs andernfalls nicht.
2. **ISO-Image einbinden:**\
   Legen Sie das OPNsense ISO-Image (Version *amd64, dvd*) über die Hyper-V Einstellungen in das virtuelle DVD-Laufwerk ein. (Pfad z. B. `\\STO-NAS-01\ISOs\OPNsense.iso`).
3. **VM starten & Live-System booten:**\
   Starten Sie die VM und öffnen Sie die Hyper-V Konsole. Warten Sie, bis der Boot-Prozess abgeschlossen ist und der Login-Prompt (`login:`) auf dem schwarzen Bildschirm erscheint. *Hinweis: OPNsense bootet zunächst immer als Live-System, nicht direkt in einen Installer.*
4. **Den Installer aufrufen:**\
   Melden Sie sich mit den Standard-Zugangsdaten des Live-Systems an:

   - **Benutzername:** `installer`
   - **Passwort:** `opnsense` (Achtung: Englisches Tastaturlayout, das ‚z‘ ist ein ‚y‘ und umgekehrt).

   Nach dem Login startet automatisch der textbasierte Installations-Assistent.
5. **Tastatur-Layout & Dateisystem wählen:**\
   Bestätigen Sie die erste Meldung mit *Accept*.

   - **Keymap:** Wählen Sie *Change Keymap* und suchen Sie nach `de.kbd.mac` oder `de.noad.kbd`, um das deutsche Tastaturlayout zu aktivieren.
   - **Installationsart:** Wählen Sie *Install (UFS)*. Zwar bietet OPNsense auch ZFS an, für eine virtuelle Maschine unter Hyper-V ist das klassische Unix File System (UFS) jedoch deutlich ressourcenschonender und performanter, da der Host (Windows) das Laufwerk ohnehin als VHDX-Datei verwaltet.

6. **Festplatte formatieren & Root-Passwort:**\
   Wählen Sie die virtuelle Festplatte (`da0`) aus und bestätigen Sie die Formatierung. Nach dem Kopiervorgang werden Sie aufgefordert, das neue Passwort für den Benutzer `root` festzulegen. Vergeben Sie hier ein **sehr starkes Passwort**, da dies der absolute Super-Admin der Firewall ist.
7. **Neustart & ISO auswerfen:**\
   Beenden Sie den Installer. Wählen Sie im Hyper-V Menü oben *Medien* → *DVD-Laufwerk* → *Datenträger auswerfen*. Bestätigen Sie danach den Reboot der VM.

> [!TIP]
> **Best Practice für Hyper-V (Integration Services):**\
> OPNsense bringt die Microsoft Hyper-V Integration Services (VMBus, Heartbeat, Time Sync) bereits nativ im FreeBSD-Kernel mit. Sie müssen hier keine zusätzlichen Treiber installieren. Das System läuft out-of-the-box mit voller 10-Gigabit-Netzwerkperformance auf den virtuellen Switches.
