# 1.4 Netzwerk-Speicher (iSCSI & SMB) Bereitstellung

## Bereitstellungs-Strategie

Die auf der UGreen DXP4800 (STO-NAS-01) erstellten Speicherpools müssen den Windows Hyper-V Hosts im Netzwerk zur Verfügung gestellt werden.

- **iSCSI (Block-Level):** Wird auf **Pool 1 (RAID 5 + NVMe Cache)** eingerichtet. Der Windows-Host sieht diesen Speicher als lokale Festplatte. Ideal und zwingend empfohlen für das Veeam Backup-Repository.
- **SMB/NFS (File-Level):** Wird auf **Pool 2 (JBOD)** eingerichtet. Dient als klassische Dateifreigabe für ISO-Dateien, Software-Archive und Benutzerdaten.

## Vorbereitung: Statische IP-Adresse für die NAS konfigurieren

Bevor iSCSI genutzt werden kann, **muss** die NAS zwingend eine statische (sich nicht ändernde) IP-Adresse erhalten. Ein Wechsel der IP-Adresse würde die iSCSI-Verbindung sofort trennen und zu Backup-Abbrüchen führen.

1. **Sichere IP-Wahl (Zwei Optionen):**\
   Um spätere IP-Konflikte im physischen LAN zu vermeiden, haben Sie zwei Möglichkeiten: Entweder Sie nutzen die Weboberfläche Ihres Routers für eine **DHCP-Reservierung** (MAC-Binding der NAS), oder Sie wählen manuell eine **freie IP-Adresse**, die idealerweise am Rand oder außerhalb des aktiven DHCP-Pools liegt (z. B. eine hohe Adresse im 192er-Netz).
2. **Einstellung im NAS (UGOS Pro):**\
   Öffnen Sie in der UGOS Pro Weboberfläche die **Systemsteuerung** (Control Panel) → **Netzwerk**.
3. Wählen Sie den aktiven LAN-Anschluss aus, klicken Sie auf **Bearbeiten** und wechseln Sie in den Reiter **IPv4**.
4. Ändern Sie die Methode von *„DHCP / Automatisch“* auf ***„Statisch / Manuell“***.
5. Tragen Sie die gewählte, sichere IP-Adresse ein.
6. Speichern Sie die Einstellungen und melden Sie sich über die neue IP-Adresse erneut an.

## Teil A: Schritt-für-Schritt Einrichtung von iSCSI (Für Veeam)

1. **SAN Manager auf der NAS öffnen:**\
   UGreen bündelt die iSCSI-Dienste in der App **SAN Manager** (Storage Area Network). Öffnen Sie das Startmenü (App-Drawer) auf dem UGOS Desktop und starten Sie diese App.\
   *Troubleshooting:* Falls die App dort nicht sichtbar ist, öffnen Sie das **App Center**, suchen Sie nach „SAN Manager“ und installieren/aktivieren Sie das Paket.
2. **iSCSI Target erstellen:**\
   Navigieren Sie im SAN Manager zum Bereich iSCSI und klicken Sie auf *Target erstellen* (bzw. iSCSI-Ziel). Notieren Sie sich den generierten IQN (iSCSI Qualified Name, z. B. `iqn.2000-01.com.ugreen:nas.target1`). Aus Sicherheitsgründen können Sie hier eine CHAP-Authentifizierung (Benutzer/Passwort) für die Verbindung festlegen.
3. **iSCSI LUN erstellen & verknüpfen:**\
   Erstellen Sie nun eine neue *LUN* (Logical Unit Number). Dies ist die eigentliche virtuelle Festplatte.

   - **Ort (Volume):** Zwingend das **Volume 1** (welches auf Speicherpool 1 / RAID 5 liegt) auswählen, damit das NVMe-Caching greift.
   - **Kapazität:** Definieren Sie die Größe für Ihre Backups (z. B. 10 TB).
   - **Verknüpfung:** Binden Sie diese LUN an das in Schritt 2 erstellte Target.
4. **Windows iSCSI-Initiator starten (Auf Host 1 & 2):**\
   Wechseln Sie auf Ihren Windows Server (Hyper-V Host). Suchen Sie im Startmenü nach **iSCSI-Initiator** und starten Sie den Dienst (Bestätigen Sie die Autostart-Meldung mit Ja).
5. **Verbindung zur NAS herstellen:**\
   Geben Sie im iSCSI-Initiator unter dem Reiter *„Ziele“* (Targets) die **statische IP-Adresse** Ihrer UGreen NAS ein und klicken Sie auf **Schnell verbinden**. Das Target sollte nun als *„Verbunden“* angezeigt werden.
6. **Datenträgerverwaltung & ReFS Formatierung:**\
   Öffnen Sie in Windows die **Datenträgerverwaltung** (`diskmgmt.msc`).

   - Ein neuer, uninitialisierter Datenträger (die iSCSI LUN) taucht auf.
   - Initialisieren Sie ihn als **GPT** (GUID-Partitionstabelle).
   - Formatieren Sie das Laufwerk zwingend mit dem Dateisystem **ReFS** (Resilient File System) und einer Blockgröße von **64K**.

> [!TIP]
> **Enterprise Best-Practice: Warum ReFS für Veeam?**\
> Die Formatierung des iSCSI-Laufwerks mit ReFS (statt NTFS) ist ein massiver Vorteil für Veeam. Veeam nutzt die ReFS-Funktion *„Fast Clone / Block Cloning“*. Bei synthetischen Vollbackups kopiert Veeam die Daten nicht physisch neu, sondern verweist nur auf bestehende Speicherblöcke. Das spart massiv Speicherplatz (Terabytes!) und reduziert die I/O-Last auf dem NAS drastisch.

## Teil B: Schritt-für-Schritt Einrichtung von SMB (Für ISOs/Dateien)

1. **Dateidienste auf der NAS aktivieren:**\
   Öffnen Sie in UGOS Pro die **Systemsteuerung** → **Dateidienste**. Stellen Sie sicher, dass der **SMB-Dienst** aktiviert ist (empfohlen: Min. SMBv2, Max. SMBv3).
2. **Freigegebenen Ordner (Shared Folder) anlegen:**\
   Wechseln Sie zum Speichermanager oder Dateimanager. Erstellen Sie einen neuen Freigabeordner mit dem Namen **ISOs**.

   - **Ort (Volume):** Wählen Sie das **Volume 2** (welches auf Speicherpool 2 / 14TB JBOD liegt) aus.
3. **Berechtigungen (ACL) setzen:**\
   Vergeben Sie Lese-/Schreibrechte für Ihren administrativen NAS-Benutzer.
4. **Einbindung in Windows (UNC-Pfad):**\
   Auf dem physischen Hyper-V Host können Sie nun über den Datei-Explorer via `\\STO-NAS-01\ISOs` (oder über die zuvor vergebene statische IP, z. B. `\\192.168.1.50\ISOs`) auf den Speicher zugreifen. Kopieren Sie als Vorbereitung für die spätere VM-Erstellung (Modul 1.6) bereits jetzt alle benötigten ISO-Dateien (Windows Server, Ubuntu, OPNsense, Kali) in dieses Verzeichnis.
